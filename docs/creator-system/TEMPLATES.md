# Templates — 最小可执行模板

## 1. Problem Note

```markdown
# P-YYYY-MMDD-XX <问题短名>

status: captured | framed | researching | judged | drafting | published | reviewed
source: self | user | comment | platform | work | study
created: YYYY-MM-DD

## 现象

## 为什么奇怪

## 真问题

## 我的初始解释（先别问 AI）

## 竞争解释
- H1:
- H2:
- H3:

## 当前核心判断

## 最大边界 / 反例

## 什么证据会让我改变判断

## 下一步最小动作
```

---

## 2. Research Note

```markdown
# R-<problem-id>

## 研究问题

## 关键定义

## Claim → Evidence

| Claim | Evidence | Challenge / Boundary | Confidence |
|---|---|---|---|
| | | | |

## 最强竞争解释

## 关键未知

## 当前结论

## 停止理由
为什么现在已经足够进入判断，而不是继续查资料？
```

## 3. Insight Atom

```markdown
# Insight

```

目标：100~500 字即可，不要求长文。

---

## 4. Canonical Draft

```markdown
# <暂定标题>

## 真问题

## 核心判断（一句话）

## 1. 现实冲突

## 2. 常见解释

## 3. 为什么不够

## 4. 更好的机制

## 5. 现实案例

## 6. 边界 / 最强反例

## 7. 可以带走什么
```

写完后删除这些模板标题也可以。模板是脚手架，不是最终文风。

---

## 5. Publish Record

```markdown
# Publish <problem-id>

platform:
url:
date:
version:

## 我想验证什么

## 入口
标题 / 封面 / 前 10 秒：

## 数据
只记 2~3 个最有意义的指标。

## 高价值反馈

## 误解

## 反例 / 反驳

## 新问题

## 对原判断的更新

## 对流程的更新
```

## 6. 10 分钟快速版

如果当天很累，只填写：

```text
今天让我觉得奇怪的是：

为什么奇怪：

我现在猜原因是：

还有一个可能解释是：

我准备查/试的唯一一件事：
```

这也算完成一次创作系统运行。不要因为不能写文章就什么都不记。
