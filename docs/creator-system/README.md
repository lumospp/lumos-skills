# Lumos Creator System V0.1

> 一个问题驱动、证据优先、AI 增强但不替代判断的个人创作系统。
>
> 当前状态：**实验版，先真实使用，再决定是否固化为 Skill。**

## 1. 这个系统解决什么

不是解决“如何批量生产内容”，而是解决：

> **如何把真实生活、学习、工作中值得想清楚的问题，经过研究、判断和表达，变成有用的公开内容，并让现实反馈继续改善自己的世界模型。**

创作不是终点，而是一个公开思考闭环：

```text
真实世界 / 学习 / 工作 / 评论 / 社会讨论
                    ↓
                发现问题
                    ↓
            找冲突 / 异常 / 困惑
                    ↓
              压成一个真问题
                    ↓
              调研与竞争解释
                    ↓
                形成判断
                    ↓
                 母稿
                    ↓
            按平台重新表达
                    ↓
                 发布
                    ↓
         评论 / 数据 / 反驳 / 行动结果
                    ↓
              更新世界模型
                    ↓
                 新问题
```

## 2. V0.1 的核心原则

1. **问题驱动，不是知识目录驱动**：不因为今天学了一个概念，就强行写这个概念。
2. **找异常，不追热点本身**：热点只用于发现长期问题；优先找“为什么明明 X，却 Y？”的认知冲突。
3. **模型服务于解释**：ICAP、奈特不确定性、古德哈特等是工具，不是选题。
4. **后台复杂，前台简单**：可以查很多资料，但一篇只打一颗钉子。
5. **一个内容只有一个核心判断**：其他内容只能作为证据、机制、反例、边界或行动建议。
6. **AI 是研究伙伴和对手，不是作者替身**：AI 可搜索、反驳、整理、改写；核心判断必须由人承担。
7. **母稿优先于多平台**：先形成一个可独立成立的内容母体，再适配平台，不为每个平台重新研究一次。
8. **发布是实验，不是交卷**：反馈用于更新判断，而不是只用于判断“爆没爆”。
9. **先跑起来，再自动化**：V0.1 禁止为了工作流本身投入大量部署时间。

## 3. 今晚直接怎么用（最小路径）

只做 6 步：

```text
1. 写下一个最近让你觉得“奇怪”的现象
2. 把它改写成一个具体问题
3. 用 AI 找 3 个竞争解释 + 关键证据
4. 自己选出当前最可信的解释，写一句核心判断
5. 让 AI 帮你把判断组织成母稿，你再修改
6. 只选 1 个平台发布
```

**今晚禁止：**

- 搭自动抓热点系统；
- 建复杂数据库；
- 同时发 4 个平台；
- 为了写作研究新软件；
- 先把全部 Prompt 优化完才开始；
- 因为资料还可以继续查而无限延迟发布。

## 4. 输入与输出

### 输入

系统允许五类输入：

- `OBSERVATION`：真实观察，例如“AI 明明讲得很清楚，但过两天我还是不会”。
- `QUESTION`：别人真实问的问题、评论区问题、自己的困惑。
- `EXPERIENCE`：自己正在做的项目、踩坑、实验结果。
- `CONCEPT`：刚学到的模型或概念，但必须继续寻找它能解释的真实问题。
- `SIGNAL`：知乎、小红书、微博、X、新闻等出现的讨论信号。

### 输出

不要求每次都写长文。允许以下输出层级：

```text
L0 Problem Note      一个值得研究的问题
L1 Insight Atom      100~500 字观点原子
L2 Short Content     小红书 / 微博 / X / 短视频口播
L3 Canonical Essay   公众号 / 长文母稿
L4 Reusable Asset    方法、模板、Prompt、Skill、产品洞见
```

大多数问题停在 L1/L2 完全正常。不要强迫每个问题都长成 3000 字文章。

## 5. AI 在系统里的位置

AI 可以承担：

- 问题澄清；
- 搜索真实讨论与证据；
- 提出竞争解释；
- 查反例；
- 建 Claim → Evidence；
- 结构整理；
- 表达压缩；
- 平台适配；
- 发布后的评论聚类与复盘。

AI 不应该替你承担：

- 这个问题是否真的值得你写；
- 你最终相信哪个解释；
- 你愿意为哪个观点负责；
- 什么与你的长期视角有关；
- 是否为了传播牺牲事实边界。

一句话：

> **AI 扩展研究和表达带宽，人保留问题选择、判断、价值与责任。**

## 7. V0.1 的成功标准

不是粉丝，不是点赞，也不是“系统搭好了”。

前 10 次运行只检查：

- 是否真的从现实问题出发；
- 是否形成了自己的判断，而非 AI 拼接；
- 是否至少找过一个竞争解释或反证；
- 是否成功发布；
- 发布后是否得到新问题或新证据；
- 整个流程有没有让你觉得重到不想开始。

如果一个环节连续 3 次让你卡住，优先删除或简化，而不是增加新的工具。
