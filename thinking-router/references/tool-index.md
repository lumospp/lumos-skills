# Thinking Tool Index — curated routing reference

This is a **working index**, not a canonical transcription of any course. It exists to improve routing recall. Use the tool that changes the problem; do not try to use the whole list.

## Worldview / framing

- Narrative — check whether a story is compressing or distorting reality.
- Heavy-tail / power-law thinking — use when a few outcomes may dominate averages.
- Hard constraints / zeroth-order truth — identify what cannot be negotiated away.
- Uncertainty as fuel — distinguish unknowns that invite exploration from risks that require protection.
- Three selves / temporal self conflict — useful when present, remembered, and future interests diverge.

## Personal growth / motivation / identity

- Self-determination theory — autonomy, competence, relatedness.
- WOOP — wish, outcome, obstacle, plan.
- Identity / role — when behavior is shaped by who the person thinks they are.
- Secure base / safe haven — when exploration depends on psychological or relational safety.
- Game selection — ask whether the person is playing a game whose rewards they actually want.
- Field / environment fit — ability and behavior depend on surrounding rules and affordances.
- Exploration–exploitation — balance searching for options vs deepening an existing one.
- Social capital / structural holes — value from relationships and bridging disconnected groups.
- Cognitive decoupling — reason about hypotheticals separately from immediate beliefs.
- Active high cognitive load — effort can be productive when it creates useful representations rather than overload.

## Decision / uncertainty / risk

- No free lunch — every strategy wins under some assumptions and loses under others.
- Distribution thinking — reason about spread, tails, skew, not only averages.
- Granularity / causal mediator — choose the right level of explanation and intermediate mechanism.
- Minimum description length — prefer simpler models when explanatory power is similar.
- Bayesian updating — combine prior beliefs with new evidence.
- Value of information — ask which unknown is worth resolving next.
- Kelly criterion — size repeated bets to protect long-term growth.
- Non-ergodicity — group averages may be dangerous for an individual path when ruin is possible.
- Fragility / antifragility — ask how volatility affects the system and whether downside is convex.
- Optionality / BATNA — preserve asymmetric upside and real alternatives.
- State leverage — choose actions that move the system into a more useful state.
- Theory of constraints / bottleneck — improve the binding constraint, not everything.
- Selection bias / survivorship bias — observed samples may systematically exclude failures.
- Regression to the mean — extreme outcomes often move back toward typical values.
- Prospect theory — people react differently to gains, losses, and reference points.
- Reference class / base rate — compare with similar historical cases before relying on inside-view stories.
- Superforecasting — decompose, calibrate, update frequently, avoid false certainty.
- OODA — observe, orient, decide, act; speed of learning can beat static plans.

## Learning / cognition

- Cognitive load theory — manage intrinsic, extraneous, and learning-relevant load.
- ICAP — distinguish passive, active, constructive, interactive engagement.
- Deliberate practice — targeted practice with feedback on weaknesses.
- Representation → schema → mental model → framework — check what level of knowledge structure is missing.
- Synthesis / research — integrate evidence rather than accumulate notes.
- Tacit knowledge — some competence is hard to transfer through explicit instructions alone.
- Desirable difficulties — useful difficulty can improve retention and transfer.
- Embodied cognition — cognition can depend on action and physical interaction.
- Human capital / signal / social capital — separate actual ability, market signal, and relationship advantage.
- Autonomy support — support choice and ownership rather than controlling motivation.
- Hugging vs bridging — near-transfer support versus explicit preparation for far transfer.

## Business / strategy / money

- Economic rent — returns above what is required to keep a resource in use.
- Alpha — excess return from information, capability, position, or edge not explained by baseline exposure.
- Leverage — code, capital, media, people, and systems amplify output.
- Opportunity window — timing changes whether an opportunity exists.
- Effectuation — start from available means, affordable loss, partners, and learning when goals/environment are uncertain.
- Causation — goal-first planning is better when objectives and causal paths are sufficiently stable.
- Wardley Mapping — map user need, value chain, and component evolution to choose where to standardize vs differentiate.
- Baumol cost disease — labor-intensive sectors may get relatively more expensive even without equivalent productivity gains.
- Jevons paradox — efficiency can increase total resource use.
- Platform / interoperability — ecosystem value depends on standards, interfaces, and complements.
- Entrustment / uncertainty reduction — people and organizations pay for reliable reduction of consequential uncertainty.

## Society / institutions / coordination

- Status — incentives often include relative rank, not only material payoff.
- Social interaction protocol — repeated coordination depends on shared expectations and conventions.
- Incentive compatibility — a mechanism works when following it aligns with participants' incentives.
- Lemons / information asymmetry — hidden quality can degrade markets.
- Verifiability — contracts and governance depend on what can be observed or proven.
- Externalities / tragedy of the commons — private incentives can create shared costs.
- Soft budget constraint — repeated rescue changes behavior and discipline.
- Legibility vs metis — centralized systems prefer measurable simplifications; local practical knowledge may resist them.
- Common knowledge — coordination changes when everyone knows that everyone knows.
- Scapegoating vs just culture — distinguish blame from system learning.
- Unintended consequences — interventions trigger adaptation and side effects.
- Lucas critique — behavior changes when policy rules change, weakening historical relationships.
- Slow variables / stable expectations — apparently stable systems may depend on gradually changing hidden states.
- Moloch / tournament dynamics — individually rational competition can produce collectively bad outcomes.
- Third object — shared external objects/tasks can stabilize collaboration better than direct interpersonal focus.

## Organization / leadership

- Residual judgment rights — who decides when rules run out?
- Organizational capital — value stored in routines, relationships, processes, and shared context.
- Narrative power — shared stories coordinate attention and action, but can also distort reality.
- Personal dependence vs role responsibility — design systems around roles, not irreplaceable heroes.
- Goodhart's law — when a measure becomes a target, it can stop measuring what mattered.
- Commander's intent — align on purpose and constraints while allowing local adaptation.
- Principal–agent — incentives and information differ between delegator and executor.
- Cogware / SOP / checklist — externalize repeatable cognition without pretending judgment can be fully scripted.
- Shifting baseline / normalization of deviance — repeated exposure can make abnormal risk feel normal.
- Claiming / granting / authorizing leadership — leadership emerges through social recognition, not only titles.

## Complex systems / evolution

- Feedback loops — outputs become future inputs; identify reinforcing and balancing loops.
- Generativity / evolvability — a system's value may come from producing new combinations and adaptations.
- Organizational closure — systems reproduce the relations that make them a system.
- Symmetry breaking / lock-in — small early differences can create persistent paths.
- Adjacent possible — choose reachable next moves that create new building blocks and future options.
- Self-organized criticality — systems can accumulate stress and release it in bursts.
- Marginal analysis — compare incremental cost and benefit rather than totals.
- S-curve / second curve — improvement saturates; new growth often requires starting another curve before the old one ends.
- Path creation — actors can create trajectories rather than merely select existing ones.
- Minimum viable ecosystem — some products require complements and coordination, not just an MVP.
- Adaptive cycle / panarchy — systems move through growth, conservation, release, and reorganization at multiple scales.

## Higher-order reflection / values

- Objective function — clarify what is actually being optimized.
- Second-order volition — distinguish what a person wants from what they want to want.
- Metarepresentation — think about representations and beliefs as objects rather than as reality itself.
- By-product / obliquity — some outcomes are better achieved indirectly than by targeting them directly.
- Self-binding — deliberately constrain future choices to protect longer-term goals.
- Moral scalability — ask whether a rule still works when generalized across people and scale.
- Problem finding / agenda setting — choosing what to solve can matter more than optimizing a given problem.
- Mesa-optimizer / inner alignment — a sub-system can optimize a proxy different from the intended objective.
- Scarcity before / after abundance — incentives and values can shift when constraints disappear.
- Pretraining vs post-training — distinguish broad learned priors from task-specific shaping and feedback.
- Exploration and generativity — keep creating new reachable possibilities rather than only optimizing a fixed path.

```text
"我该选哪条路？" → objective function / game selection / optionality
"我现在根本不知道目标是否对" → effectuation / adjacent possible
"平均回报看起来不错但我怕一次翻车" → non-ergodicity / fragility / Kelly
"大家都这么做，所以我也应该？" → reference class + selection bias
"指标越来越好，现实越来越差" → Goodhart + principal-agent / incentive compatibility
"系统越来越复杂但没改善" → bottleneck / state leverage / hard constraints
"我学了很多却不会用" → ICAP / cognitive load / deliberate practice / transfer
"怎么授权又不失控" → commander's intent + residual judgment rights + principal-agent
"产品线到底哪里该自研" → Wardley Map + bottleneck / evolution
"我想自由，但不知道是不是只是逃离" → objective function + second-order volition + game selection
```

Use this index to improve recall, not to turn every answer into a framework catalogue.
